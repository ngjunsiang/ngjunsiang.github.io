Start writing

  1. New draft — the filename, date and permalink are generated for you.
  2. Write — WYSIWYG or markdown source, autosaved to _drafts/.
  3. Preview — the pane on the right is your real site, rendered by jekyll serve --drafts.
  4. Publish — moves the draft into _posts/, then commit, push and open a PR without leaving the page.

Drafts never deploy: CI builds without --drafts. A post goes live only when its PR merges to main.
